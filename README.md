## ✅ Tasks Completed  

### 1. 🌸 Iris Flower Classification  
**Objective:** Classify iris flowers into three species (*Setosa, Versicolor, Virginica*) using petal & sepal measurements.  

**Workflow:**  
- Loaded dataset (UCI Repository / scikit-learn).  
- Data visualization with scatter plots & histograms.  
- Train-test split.  
- Trained models: Logistic Regression, KNN, Decision Tree.  
- Evaluated using **Accuracy & Confusion Matrix**.  

**Skills Gained:** Data visualization, classification, model evaluation.  

---

### 2. 📧 Spam Mail Detector  
**Objective:** Build a model to detect spam vs ham emails using text data.  

**Workflow:**  
- Used SMS Spam Collection dataset.  
- Preprocessed text (lowercasing, stopword removal, tokenization).  
- Feature extraction with **TF-IDF**.  
- Trained models: Naive Bayes, Logistic Regression.  
- Evaluated with **Accuracy, Precision, F1-score**.  

**Skills Gained:** Text preprocessing, NLP basics, feature extraction, classification.
